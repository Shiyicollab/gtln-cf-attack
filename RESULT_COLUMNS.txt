Raw records: results/raw_trials.csv
Each row describes one complete attack on one generated key.

set_id,trial               Parameter-set ID (1-24) and trial index within that set (starting at 0).
n,t,b,beta,G               Key-generation parameters and modulus bit length G.
Cp,Cg                     Fixed cofactor search caps used by the attack.
status                    Output status, such as unique, ambiguous, or no_candidate.
attack_s                  Complete attack time, in seconds.
cf_s                      Time for public-input checks, continued fractions, residual checks, and endpoint gcds.
endpoint_s                Time for endpoint enumeration, reconstruction of other coordinates, and pairwise-coprimality checks.
modulus_s                 Time for the modulus gcd, modulus enumeration, and public-equation verification.
keygen_s                  Key-generation time; excluded from attack_s.
endpoint_scans            Total number of cofactor integers tried across both endpoints.
endpoint_candidates_lo    Number of candidate integers for the smallest-public-entry endpoint.
endpoint_candidates_hi    Number of candidate integers for the largest-public-entry endpoint.
endpoint_pairs            Number of endpoint candidate pairs examined.
endpoint_gcd_rejections   Number of pairs rejected because the endpoints are not coprime.
reconstruction_rejections Number of pairs rejected due to an invalid reconstruction denominator, inexact division, or an out-of-range coordinate.
coprimality_rejections    Number of complete vectors rejected because their coordinates are not pairwise coprime.
integer_vectors           Number of integer vectors passing all coordinate checks and reaching modulus recovery.
modulus_scans             Number of modulus cofactors tried.
public_validations        Number of candidates reaching verification of all public equations.
public_sha256             SHA-256 of the public-key list serialized with Python's json.dumps(public), for checking sample identity.
unique_exact              Whether the output consists of exactly the original private key: 1 for yes, 0 for no.
truth_in_candidates       Whether the original private key is in the returned candidate set.
candidate_count           Number of returned candidates.
ratios_exact              Whether all recovered intermediate ratios match those computed from the original key.
ratio_count               Number of intermediate ratios computed; n-2 in a complete run.
f_lo,f_hi,c               True cofactors for the two endpoints and the modulus, measured using the original key.
true_Fg                   The value floor(g0/(max(t_i)+1)) for the true private integer vector.
caps_cover_truth          Whether all three true cofactors lie within the fixed search caps.

The original private key is used only for evaluation after the attack timer
stops. The evaluation fields above are not available to the attack.

results/summary.csv and results/summary.json contain per-parameter trial and
success counts, mean/median/95th-percentile/maximum attack times, maximum
observed search counts, and cofactor statistics. All *_s fields use seconds.
The JSON summaries also include count distributions. In these summaries,
integer_vectors is a histogram of the number of accepted integer vectors.

results/aggregate.json contains overall statistics for all 2,400 trials.
results/metadata.json records Python, operating system, CPU, seed, input
parameters, sampling procedure, timing scope, start/end times, and source hashes.
results/public_set_01.json through results/public_set_24.json contain the first
sample public key from each parameter set. They contain no private keys.
